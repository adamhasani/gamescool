How we count
In a game
A visible tab on a game with a tap, key, click or controller input in the last 90 seconds. Tabs of one browser count once.
On the site
Every open tab of Gamescool, including the shelf and background tabs.
Players
Browsers that opened a game, counted once per calendar month. A player who comes back next month counts again.
Plays
A play starts when someone opens a game after 30 minutes or more away from it.
Hours played
Time in a game with recent input. Idle and background tabs do not count.
Meme Surge runs
Runs started: solo Survival, District and Road runs, and finished co-op squads, from the game's own records.
Before the live count
Days before the live count come from the server's request log: a game counts as opened when its own art or API was loaded, not the shelf cover. Peaks and hours start with the live count.

Counts only. No names, addresses or cookies appear here. All times UTC.
